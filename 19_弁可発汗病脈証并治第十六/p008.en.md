# §8 (English translation)

## Translation of the text

When a disease has a floating large pulse and on questioning the patient says there is only hard stool, if it is purged, it is a great adverse treatment. Hardness is repletion, yet sweating resolves it. Why? Because the pulse is floating, it should be resolved by sweating.

## Translation of Cheng Wuji's commentary

The classic says: "When the pulse is floating and large, sweating should be induced; if the physician, on the contrary, purges it, it is a great adverse treatment." Although hard, difficult stool is interior repletion, one should still first resolve the exterior; using purgative medicine would be a great adverse treatment. Even with urgent chest binding, if the pulse is floating and large, it must not be purged, and purging it causes immediate death—how much more with mere difficult stool! The classic says: "Where sweating should be induced, purging it again is adverse; if sweating is induced first, the treatment is not adverse."

## Notes

The clause states that even with constipation, if the pulse is floating and large and an exterior pattern remains, it should first be resolved by sweating, not purgation. It has the same purport as the principle of not purging while an exterior pattern remains (Clause 44 of the middle taiyang chapter, etc.).
