# 弁発汗後病脈証并治第十七

## 篇首の注

**【注釈】この篇の Wikisource・Kanripo の本文について**

Wikisource と Kanripo（成無己『注解傷寒論』系）のこの篇は，最後の1条（ベースの「発汗多。亡陽讝語者…」）と，その後の次の一文だけからなる。注解本では，この篇の条文は前の篇（六経の篇）に詳しく載っているとして省いている。ベースにあって両者にない条文は記録していない。

なお，ベース（儒道中医網）のこの篇は条文だけで，宋本の可・不可の篇にあるはずの方（構成と煎じ方）を載せていない。両者にも方はないため，補えていない。

【注釈】Wikisource では，この篇から「巻第八」。Kanripo は巻第七と巻第八を分けず，「註解傷寒論巻第七之八」の中に続ける。
