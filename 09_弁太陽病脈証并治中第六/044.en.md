# Clause 44 (English translation)

## Translation of the text

Taiyang disease: when the external pattern has not yet resolved, one must not purge; purging it is a mistake. When one wishes to resolve the exterior, Guizhi tang is appropriate. 14. Use the twelfth formula above.

## Translation of Cheng Wuji's commentary

The Classic says: "When sweating should originally have been induced but purgation is applied instead, it is a mistake. If one treats by first inducing sweating, it is not a mistake."

## Notes

This clause states the principle of treatment order (first the exterior, then the interior): while the exterior pattern remains, purgation must not be used. Even if there is interior repletion, the rule is first to resolve the exterior and then attack the interior (see also Clause 90).
