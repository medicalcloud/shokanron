# Clause 45 (English translation)

## Translation of the text

Taiyang disease: when sweating was first induced without resolution and then purgation was applied, if the pulse is floating, [the patient] does not recover. A floating pulse means [the disease] is in the exterior; it was purged instead, and therefore did not recover. Now the pulse is floating, so it is in the exterior; one must resolve the exterior, and then [the patient] will recover. Guizhi tang is appropriate. 15. Use the twelfth formula above.

## Translation of Cheng Wuji's commentary

The Classic says: "When the Chaihu tang pattern is complete but it is purged with another medicine, and the Chaihu tang pattern is still present, give Chaihu tang again." This is a case in which, although purgation has already been applied, it does not count as a mistake; [this clause] is of the same kind.

## Notes

If sweating did not resolve the disease and, after mistaken purgation, the pulse is still floating, the evil is still in the exterior, so the exterior should again be resolved with Guizhi tang. It shows the idea that even after mistaken purgation one may return to the original treatment if the pattern has not changed (the same purport, says Cheng Wuji, as the Chaihu tang example in Clause 149).
