# §8 (English translation)

## Translation of the text

Where sweating should be induced, purging it again is adverse; if sweating is induced first, the treatment is not adverse. Where it should first be purged, inducing sweating instead is adverse; if it is purged first, the treatment is not adverse.

## Notes

The same content as Clause 90 of the middle taiyang chapter, where Cheng Wuji's commentary is found.
