# §62 (English translation)

## Translation of the text

Cold damage of five or six days with retching and fever: the Chaihu tang pattern is present, but it was purged with other medicines. When the Chaihu pattern is still present, give Chaihu tang again; although it has already been purged, this is not adverse; there will certainly be steaming and shaking, followed by fever and sweating, and it resolves. If there are fullness, hardness, and pain below the heart, this is chest binding; Da Xianxiong tang governs it; use the previous formula. If there is only fullness without pain, this is glomus; Chaihu is not suitable to give; it belongs to Banxia Xiexin tang. [The base contains the meaningless string "$u{" in two places, thought to be a remnant from conversion of the source; it is ignored in the translation.]

## Notes

The same content as Clause 149 of the lower taiyang chapter, where Cheng Wuji's commentary is found. The "$u{" in the base is thought to be an intrusion of symbols that are not part of the text.
