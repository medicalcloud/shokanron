# 注解傷寒論の付属部分

Kanripo の成無己『注解傷寒論』（KR3e0008，四部叢刊所収の明 汪濟川本）にあり，宋本（ベース）にない部分をまとめたもの。本文のどこにも対応する箇所がないため，篇とは別にこのディレクトリに置く。このファイルは 作業用のスクリプト が作る。字体の方針を適用した（Kanripo の「丼」は「甘」に，「已」の意の「巳」は「已」に直した）。

Kanripo の注解本にあるもののうち，宋校序（傷寒論序）と張仲景序（傷寒卒病論集）は宋本にもあり，`02_傷寒論序`・`03_傷寒卒病論集` で照合した（校正官の公文書は `02_傷寒論序_注釈.md`）。
