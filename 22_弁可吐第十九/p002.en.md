# §2 (English translation)

## Translation of the text

In general, when using an emetic decoction, stop as soon as it hits the disease; it is not necessary to finish the preparation.

## Translation of Cheng Wuji's commentary

The essential is to be appropriate; one does not want excess.

## Notes

The clause states the principle that an emetic should not be used further once it has taken effect. It has the same purport as paragraph 3 of the "May Be Sweated" chapter.
